# Lessons

Each lesson is a self-contained scenario that teaches one production-grade Terraform skill.

## How to progress
- Read `lessons/<n>/README.md` to understand the scenario and the deliverable.
- Open `lessons/<n>/starter/` and implement the missing Terraform.
- Use `lessons/<n>/checks.md` to self-verify before you move on.
- Use `lessons/<n>/hints.md` when you get stuck.

## What this course optimizes for
- Correct Terraform language usage
- Correct GCP modeling with explicit APIs, networking, IAM, secrets, and services
- Operational safety: remote state, review gates, environment separation
