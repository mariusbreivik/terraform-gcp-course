# Solutions

This course is exercise-first.

No full answer keys are included in this repository, because the goal is to help learners practice building Terraform for a new GCP organization.

## How to self-check instead of solutions
- Use `lessons/<n>/checks.md` for acceptance-style checks.
- Use `lessons/<n>/hints.md` when you are blocked.
- Rely on Terraform output inspection:
  - review the plan for creates/updates/deletes
  - confirm outputs match the identifiers other lessons expect

## Optional: how to use solutions later
If you add answer keys in the future, keep them here so the main workbook stays clean and the learner workflow remains consistent.
