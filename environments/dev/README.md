# Dev Environment

Dev is for experimentation. The goal is to move fast while still practicing safe infrastructure habits.

## Typical dev characteristics
- Faster iteration and safer defaults
- Reduced blast radius for changes
- Separate IAM boundaries and state from prod

## What to focus on in this course
- Dev-specific state prefix and remote state configuration (Lesson 5)
- How dev overlays consume shared foundation and modules (Lesson 6)
